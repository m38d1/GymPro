## 🚀 اجرا

### روش ۱ — بدون هیچ کاری
فایل `index.html` را با مرورگر باز کن (دابل‌کلیک). تمام. آفلاین است.

### روش ۲ — نصب به‌عنوان اپ (PWA)
برای نصب، سرویس‌ورکر نیاز به `http(s)` دارد:

```bash
cd GymPro
python3 -m http.server 8080
# در موبایل: http://IP-این-کامپیوتر:8080 را باز کن
# در Chrome/Edge: دکمۀ «📲 نصب اپ» یا منوی Add to Home Screen
```

یا روی GitHub Pages منتشرش کن (Settings → Pages → از همین ریپو).

## 🧪 تست‌ها

تست‌ها با [jsdom](https://github.com/jsdom/jsdom) جریان کامل را می‌روند:
ویزارد → انتخاب برنامه → تیک حرکت → تایمر → نقشۀ عضلات → localStorage.

```bash
cd tests
npm init -y && npm i jsdom   # یک‌بار
node t_wizard.js             # ویزارد و ساخت برنامه
node t_v4.js                 # تایمر استراحت و نقشۀ عضلات
```
